# Dynamic Events

You must pass all 6 stages of [scrutineering](../scrut/index.md) before you compete in any dynamic events.
The FTX7 car did not compete in any dynamic events as we did not pass scrut.
In previous years, the FTX6 car competed in sprint and a few laps of the endurance event.

The dynamic events are:

- Skid Pad
- Acceleration
- Sprint
- Endurance / Efficiency
