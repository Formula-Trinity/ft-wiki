# Safety

**Note:** *Technical and Safety scrutineering are typically done at the same time, so line between the two is blurred*

Safety Scrutineering assesses whether the car can be operated safely. This includes both specific rule requirements and also more general hazards identified during inspection.

Scrutineers might raise concerns even when there is no rule directly describing the issue, particularly where workmanship, component security, sharp edges, routing or access could create a safety risk. Some judgement and common-sense is therefore involved, and concerns can vary between scrutineers.
