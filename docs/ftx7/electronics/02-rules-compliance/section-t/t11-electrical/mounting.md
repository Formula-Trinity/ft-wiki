# T11.11 — Sensors and Electrical Components Mounting

[Rules and Compliance](../../index.md) / [Section index](index.md)

Include the ECU, dashboard, switches, sensors, antennas and cameras in the installed-component layout. Alternative sensor and antenna placements must be justified individually.
