# Connectors 

## Why do we need them?

Connectors create removable electrical connections between components and sections of the wiring harness. Each wire is crimped to a metal terminal, which is pushed into a plastic housing, and the two halves of the connector then clip together. They allow components and sub-harnesses to be removed without cutting or permanently altering the wiring.

Connectors make it easier to:

- install and remove the wiring harness
- replace components
- disconnect sensors and engine components
- test individual circuits
- locate electrical faults

Connectors must be rated for the voltage and current carried by the connected wires.

## FTX7

For FTX7, connectors are used throughout the main harness and removable sub-harnesses. This allows the harness, electronics plate, sensors and engine components to be disconnected and removed more easily than on FTX6, where the harness was wired in semi-permanently.

The FTX7 design report states that sealed automotive connectors rated for their expected current were used.
