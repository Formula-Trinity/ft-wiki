## How to use this register

Read the rule text through the links to the [wiki rules folder](../../rules/index.md). Each compliance entry records the FTX7 approach, verification needed, status and evidence/result field. The current design descriptions come from the electronics overview and linked subsystem pages. Many of those pages are still placeholders, so a design description or link alone does not demonstrate compliance.

| Status | Meaning |
|---|---|
| Open | Applicable; design details and/or verification evidence are still missing. |
| Conditional | Applicability depends on fitted equipment, configuration or an event decision that still needs recording. |
| Not applicable | Excluded for the documented configuration, with the reason recorded; revisit if the configuration changes. |
| Verified | Use only after linking evidence for every part of the rule, with the tested configuration/revision, reviewer and date. No entries are initially marked verified. |
