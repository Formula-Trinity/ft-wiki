# File Structure

Keeping a standardised, easy to understand file system makes viewing, editing and manufacturing parts easier. The file naming system for FTX-8 is detailed below.

## Naming Convention

**ALL** SolidWorks parts must follow this file naming convention:

### DEP-SUB-NUM - PLAIN ENGLISH PART NAME

**DEP: A three letter abbreviation of the department name that the file belongs to:**

- AER = Aerodynamics
- CHA = Chassis
- DTR = Drivetrain
- ELE = Electronics and Tuning
- PWR = Powertrain
- SUS = Suspension

**SUB: A three letter abbreviation for the subsystem that the part belongs to within its department:**

A few examples...

- BRK = Braking System
- INT = Intake
- STR = Steering
- BDY = Bodywork

**NUM: 4 digit part number within department**

*First two digits: Sub-assembly number*

For example:

For suspension

- 01 may be steering
- 02 may be uprights

*Second two digits: Part number within subassembly*

Using the same suspension example;

- 0101 Is the first part in the steering subassembly, say the steering wheel
- 0102 Is the second part in the steering subassembly, say the steering column

**PLAIN ENGLISH PART NAME: A short, simple, description of the part**

Allows the part to be easily identified by the file name, keep as concise as possible

So, using this system and the suspension examples from earlier...

The file name for the steering wheel would be ***SUS-STR-0101-STEERING WHEEL***

The file name for the steering column would be ***SUS-STR-0102-STEERING COLUMN***

The file name for a front upright would be **SUS-UPR-0201-FRONT UPRIGHT**
