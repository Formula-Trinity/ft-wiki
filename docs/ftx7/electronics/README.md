# Formula Student IC Electronics Wiki Scaffold

A ruleset-agnostic Markdown structure for an internal-combustion Formula Student car.

Start at `index.md`. Each subsystem page contains prompts for requirements, interfaces,
failure modes, testing, manufacturing, service and evidence.

Before using it for compliance:
- select the exact competition and rules version;
- update `01-rules-compliance/rules-register/index.md`;
- remove optional systems that are not fitted;
- verify all rule references against the competition's current official documents.
